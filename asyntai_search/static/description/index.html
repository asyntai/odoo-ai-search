Set up in two minutes

  1. Install the module and open Asyntai AI Search in the app switcher
  2. Press Connect Asyntai and sign in, or create a free account
  3. Done. We read your shop, and the bar switches on by itself

Works with Odoo 16, 17, 18 and 19, on Odoo.sh or your own server. Needs the Website app; with eCommerce installed, your products are searched too.

Where the bar appears

  • Automatic. Replaces the header search box if your site shows one, otherwise adds the bar to the header. Exactly one bar, never two
  • In place of the search box my site already shows
  • Add the bar to the site header. Every Odoo header layout, on desktop and in the mobile menu
  • Only where I add the block myself. Drop an HTML block with <div data-asyntai-search></div> wherever the bar should go

Free to start

The search bar runs on every plan, including the free one. If you use up your monthly allowance, your normal Odoo search takes over until it resets, so visitors can always search.
